# Seraphina

Reading site for *Seraphina*, a young adult fantasy trilogy by Melanie Dobson: *Resonance*, *Echoes*, and *Ascendance*.

The books are for invited readers. Chapter files in `data/` are encrypted and can only be opened by signing in on the site.

This repository is generated. Edit the manuscripts and site template in the private Seraphina repo, then rebuild with `tools/Build-Website.ps1`.
